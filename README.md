# 健康問卷與產品推薦工具

## 健康問卷：僅儲存完成結果

- 問卷首頁：https://spa-gemini-ai.vercel.app/（仍免登入）。
- 歷史紀錄後台：https://spa-gemini-ai.vercel.app/health-history/（獨立管理員密碼）。
- 完成結果（包含 Track A、Track B，以及極低分特殊警示）生成後，系統立即以匿名唯一 UUID 自動寫入 **Vercel Private Blob**。填寫過程、未完成的草稿、姓名、電話及 IP 不寫入紀錄。
- 第一頁有明確的結果儲存告知與勾選同意；未勾選無法繼續填寫。僅在進入結果頁時傳送一次，若網路失敗可於結果頁手動重試；儲存成功會顯示紀錄編號。已關閉頁面但上傳未成功的結果無法保證回復。
- 後台可查看記錄時間、四項自評分數、所選症狀／生活習慣／目標、當時的健康文字解析、核心營養素描述，以及當時的推薦產品名稱、品牌與描述。這些資料是當時結果的**靜態快照**，不會因日後問卷產品與矩陣修改而改動。
- 後台支援查看、搜尋已載入的紀錄、列印與永久刪除；管理員登入採用 HttpOnly/Secure/SameSite Cookie，會話上限 12 小時，不在瀏覽器 localStorage 儲存密碼。
- 管理密碼由 Vercel 環境變數 \`HEALTH_ADMIN_PASSWORD\` 提供；未設定時沿用既有的 \`PRIVATE_TOOLS_PASSWORD\`。**務必使用高強度密碼，不要在前端 HTML 寫入管理密碼**。
- 來源：\`api/health-results.js\`（匿名結果寫入、驗證後列出／查看／刪除）、\`api/health-admin.js\`（登入）、\`tools/健康問卷紀錄.html\`（後台）。
- 公開結果寫入 API 透過請求來源與資料格式檢查減少誤用，但**不等同於身分驗證或防刷機制**；如將問卷大量公開，應另外增加速率限制、反機器人防護、異常監控及資料保留期限規則。
- 本次沿用已連接的 Vercel Private Blob，而未使用目前屬於其他專案的 Supabase 資料庫，不需另建新的雲端服務。請注意儲存空間容量和讀寫用量。

## 快速產品推薦清單

新頁面聚焦四件事：

1. 上方搜尋品名、品牌或產品 P 編號，使用三欄大卡片快速勾選。
2. 下方以兩欄卡片顯示已選產品圖片、名稱、品牌及參考價格。
3. 從 Vercel Private Blob 自動載入「圖片核對中心」已核准的圖片，不需每次匯入 ZIP。
4. 使用型錄既有 `headline`、`brief` 生成短功能描述，可逐項編輯或還原預設。選擇「下載推薦單」（含圖、價格、描述且離線可開啟 HTML）或「複製文字」（可貼 LINE）；已移除 PDF 列印按鈕。

不提供數量調整、售價修改、CSV 匯入及 ZIP 圖片匯入等管理操作，以維持快速選品。品名與售價直接來自原始型錄的 `BASE_PRODUCTS`；修改功能描述只儲存於目前瀏覽器 localStorage，**不會寫回原始型錄、健康問卷或雲端資料庫**。已選產品與描述可用「清空」一併重置。

**注意：** 這個簡化工具不依照健康問卷自動挑選商品，它是供內部人員勾選產品後產生客戶推薦清單。推薦給客戶的 HTML 會嵌入成功載入的產品圖片。未核准或無法讀取的圖片會顯示為「尚無圖片」。

## 檔案對應

- `spa_gemini_ai.html`：原始健康問卷，完整保留。
- `tools/圖片核對中心.html`：原始圖片核對及批次 ZIP 工具，完整保留。
- `cloud-sync-review.js`：人工核准後傳送照片到私有雲端並撤回圖片。
- `tools/產品選購清單.html`：**先前完整功能版備份及產品資料來源**，不再發布在快速推薦清單網址。
- `tools/簡易產品推薦清單.html`：現在發布的新頁面，提供搜尋、勾選與預覽。
- `simple-recommendations.js`：勾選、雲端圖片載入、價格顯示、可編輯短描述、複製文字及下載 HTML。
- `build-site.mjs`：讀取原始清單 HTML 的 `BASE_PRODUCTS`（目前 141 項），自動生成 `recommendation-list/catalog.js`，避免再手動維護第二套產品名稱。
- `api/product-images.js`：後端私有 Blob 圖片 API；免登入讀取，新增與刪除圖片只接受同源網頁的 JSON 請求（此檢查無法取代身分驗證）。
- `vercel.json`：工具頁和雲端圖片 API 的路由設定；不再使用 Basic Auth Middleware。

## 圖片操作與備份

平時請到圖片核對中心：選產品 → 貼上圖片 → 勾選核對 → 核准。
雲端核准成功後，即可回到快速產品推薦清單勾選對應商品，圖片會自動出現。

舊版的本機已核准圖片可以先「還原既有圖片 ZIP」，再按「首次同步舊圖片」一次搬移。原始 ZIP 匯入／匯出仍在圖片核對中心，作為備份用途。

所有圖片目前儲存在 Vercel 私有 Blob，並按 `product-images/approved/P001.jpg` 等 ID 命名。Blob 存取權杖仍留在 Vercel 伺服器端，不會傳給前端；工具頁與圖片 API 已取消帳密驗證，同源請求檢查不構成真正的存取控制。

## 限制及驗收

- 原始完整型錄中的產品名稱與其他資料未做外部官網更新核對。
- 新版畫面與功能已經過程式語法、建置及部署狀態檢查，但還須在瀏覽器實際確認圖片出現、HTML 下載與手機響應式顯示。
- GitHub 儲存庫為公開；取消 Basic Auth 後，三個頁面及圖片讀取皆可匿名存取。圖片核對中心亦可在同源瀏覽器中新增或刪除圖片，請勿將工具網址視為私人空間。
- 如作商業用途，請確保 Vercel 服務方案符合其商用條款。
